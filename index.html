🍳 Recipe Box API

Your digital cookbook backend

This RESTful service allows developers to seamlessly store, organize, search, and manage culinary recipes, ingredients, and collections.

Key Capabilities:

  • Full CRUD operations for recipes and categories.
  • Advanced filtering by ingredients and preparation time.
  • Secure user authentication powered by Flask-JWT-Extended.
🔒 Authentication Note: Protected endpoints require a valid token. Click the **Authorize** button in Swagger and pass your token using the exact format: Bearer <your_token>.
